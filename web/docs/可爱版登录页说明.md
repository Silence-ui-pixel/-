# 可爱卡通互动版登录页 · 资源与配置说明

## 一、新增文件清单

```
src/views/login/
├── index.vue                    登录页主文件（整合卡片 + 卡通 + 光标 + 状态联动）
└── components/
    ├── BgAnimation.vue          背景动画层（原有，未改动）
    ├── Mascot.vue               卡通人物组件（内联 SVG + 状态机动画）
    └── CustomCursor.vue         Hello Kitty 光标组件（内联 SVG data URI + 降级）
```

## 二、卡通人物（Mascot.vue）

### 实现方式
- **纯内联 SVG 手绘**，无外部 PNG 依赖，体积约几 KB
- 通过 `state` prop 传入状态，CSS 类控制动作

### 状态机（5 种状态）

| 状态 | 触发时机 | 动作 |
| --- | --- | --- |
| `idle` | 默认 | 轻微晃脑袋 + 眨眼睛 + 小幅摇摆身体 |
| `hover` | 鼠标悬浮卡通人物 | 歪头 + 挥手 + 蹦一下 |
| `peeking` | 表单输入框聚焦 | 偷看输入框（身体前倾 + 探头） |
| `loading` | 登录请求中 | 加油等待（小幅蹦跳打气） |
| `success` | 登录成功 | 开心比耶（蹦跳 + 咧嘴笑 + 比耶手） |

### 状态优先级
`loading > success > peeking > hover > idle`（在 `index.vue` 的 `mascotState` computed 里定义）。

### 如何替换成自己的图片
卡通人物目前是 SVG。如果你想用 PNG 素材：

1. 在 `Mascot.vue` 里把 `<svg>...</svg>` 整个删掉
2. 换成：`<img :src="imageSrc" class="mascot-img" alt="" />`
3. 把 PNG 放到 `public/mascot/` 目录，`imageSrc` 指向 `/mascot/xxx.png`

> 注意：如果换 PNG，需要准备多张不同动作的图（idle/hover/peeking/loading/success 各一张），
> 通过 `:class` 切换显示。当前 SVG 方案用单个图形 + CSS 动画控制动作，更轻量。

## 三、Hello Kitty 光标（CustomCursor.vue）

### 实现方式
- 光标图片是**内联 SVG 的 data URI**，直接写在 CSS 的 `url("data:image/svg+xml,...")` 里
- 不依赖外部文件，无网络请求

### 两套光标

| 光标 | 触发 | 样式 |
| --- | --- | --- |
| `--cursor-default` | 默认全局 | Hello Kitty 基础头像（圆脸 + 蝴蝶结 + 胡须） |
| `--cursor-pointer` | 按钮/输入框/链接等可交互元素 | Hello Kitty 举手（打招呼） |

### 降级机制（重要）
每个 `cursor` 都写了两个值：

```css
cursor: url("data:image/svg+xml,..."), auto;   /* 默认：加载失败回退 auto */
cursor: url("data:image/svg+xml,..."), pointer; /* 可交互：加载失败回退 pointer */
```

当浏览器不支持 SVG cursor 或图片加载失败时，自动使用后面的 fallback 关键字，
**不影响输入和点击操作**。

### 如何替换成自己的 PNG 光标
1. 准备 PNG 光标图（建议 32×32，透明背景）
2. 放到 `public/cursors/` 目录
3. 在 `CustomCursor.vue` 的 style 里，把：

```css
--cursor-default: url("data:image/svg+xml,..."), auto;
```

改成：

```css
--cursor-default: url("/cursors/kitty-default.png") 16 16, auto;
```

> `16 16` 是光标热点（hotspot），即点击生效的精确位置，通常是图片中心点。

## 四、状态联动逻辑（在 index.vue）

卡通人物的状态由几个 `ref` 驱动，通过 `computed` 汇总：

```ts
const isInputFocused = ref(false)  // 输入框聚焦 → peeking
const hovered = ref(false)         // 鼠标悬浮卡通 → hover
const isSuccess = ref(false)       // 登录成功 → success
const loading = ref(false)         // 请求中 → loading
```

各输入框的 `@focus` / `@blur` 事件更新 `isInputFocused`，
卡通人物容器 `@mouseenter` / `@mouseleave` 更新 `hovered`，
登录成功时置 `isSuccess = true`，停留 1.2s 展示比耶动画后跳转。

## 五、视觉平衡原则

- 卡通人物放在**卡片右侧**（移动端移到上方），不遮挡表单
- 配色沿用低饱和蓝紫灰（`#7d8bb0`、`#b9c4de`、`#e8a7b8` 腮红），与背景渐变融合
- 动画节奏慢（摆动 5s 周期、眨眼 4.5s 周期），不频繁抖动
- 卡通人物是「装饰点缀」，尺寸 150px，不喧宾夺主
