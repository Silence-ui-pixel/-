# 登录页（深色动效版）· 使用说明

## 一、效果概览

基于 Vite + Vue3 `<script setup lang="ts">` + TypeScript + Element Plus，参考腾讯 Marvis 工作台登录页的视觉风格，实现了一套**深色、低饱和、低对比**的商务风登录页。

包含：
- 多层柔和渐变背景缓慢流动（蓝紫 / 灰蓝，呼吸感）
- 细碎光点粒子漂浮淡入淡出（数量少、不密集）
- 微弱光带丝滑游走（透明度极低，作底层烘托）
- 登录卡片初次上浮淡入 + 永久极轻微悬浮 + hover 柔和阴影
- Element Plus 输入框聚焦底部线条伸展、按钮微光扩散与按压回弹
- 完整响应式 + `prefers-reduced-motion` 无障碍适配

## 二、文件结构

```
src/views/login/
├── index.vue              登录页主文件（卡片 + 表单动效）
└── components/
    └── BgAnimation.vue    背景动画层（独立拆分，可复用）

src/styles/
└── _variables.scss        全局 SCSS 变量（颜色 / 动效 / 圆角统一管理）
```

## 三、如何在现有 Vite 项目引入

### 1. 安装依赖（若未安装）

```bash
npm install -D sass
```

> 本页面使用 SCSS，需要 `sass` 支持。未引入任何大体积动画库（纯 CSS 实现，无 GSAP）。

### 2. 复制文件

1. 把 `src/views/login/` 整个目录复制到你的项目对应位置
2. 把 `src/styles/_variables.scss` 复制到你的样式目录（或自己建一份变量文件）

### 3. 调整变量文件路径

`index.vue` 和 `BgAnimation.vue` 里通过 `@use '@/styles/variables' as v;` 引入变量。
如果你的项目 `@` 别名指向的不是 `src`，需要在 `vite.config.ts` 确认：

```ts
resolve: {
  alias: {
    '@': fileURLToPath(new URL('./src', import.meta.url)),
  },
},
```

### 4. 接入路由

在你的路由里挂上登录页：

```ts
{
  path: '/login',
  name: 'login',
  component: () => import('@/views/login/index.vue'),
}
```

### 5. 替换登录逻辑

登录逻辑在 `index.vue` 的 `onSubmit()` 里，当前是「假登录」。
接入真实后端时，替换 `fakeLogin()` 为你的真实接口调用即可：

```ts
// 把这里
await fakeLogin()
// 换成
const res = await loginApi({ username: form.username, password: form.password })
auth.login(res.username, res.displayName, res.role)
```

## 四、核心设计说明

### 颜色体系（`_variables.scss`）
所有颜色集中在 `_variables.scss`，改主题只需改这里：

| 变量 | 用途 |
| --- | --- |
| `$bg-deep` | 页面最深背景 |
| `$bg-grad-1/2/3` | 三层渐变光斑颜色 |
| `$card-bg` | 卡片半透明玻璃底色 |
| `$brand` / `$brand-hover` | 品牌主色（低饱和蓝） |
| `$text-primary/secondary/muted` | 三级文字颜色 |

### 动效时间函数
统一使用 `cubic-bezier(0.22, 1, 0.36, 1)`（自然缓动，先快后慢带阻尼），
定义在 `$ease-out` 变量里，全站一致。

### 性能
- 背景动画 **纯 CSS 实现**（`transform` + `opacity` + `filter`），
  全部走 GPU 合成层，不触发重排，避免卡顿
- 粒子只有 6 个，数量少、不密集
- 使用了 `will-change` 提示浏览器预优化，但仅对有限的几个元素

### 无障碍
系统开启「减弱动态效果」时（`prefers-reduced-motion: reduce`），
背景渐变、光带、粒子、卡片悬浮动画**全部关闭**，只保留静态背景和表单。

## 五、可调参数速查

| 想调什么 | 改哪里 |
| --- | --- |
| 背景流动速度 | `_variables.scss` 的 `$dur-bg-drift` |
| 卡片悬浮幅度 | `index.vue` 的 `card-float` keyframes（`translateY(-6px)`） |
| 粒子数量 | `BgAnimation.vue` 里 `.particle` 的个数和位置 |
| 卡片宽度 | `index.vue` 的 `.login-card` 的 `width` |
| 品牌主色 | `_variables.scss` 的 `$brand` |
