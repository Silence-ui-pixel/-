## 两条硬约束

1. **不要连数据库。** 所有数据走 `/api/v1`。你需要什么字段，找 A 加接口，不要自己查表——表结构一变两边一起崩。
2. **不要改 `contracts/`。** 契约是 A 负责的，要改先提 issue，两人确认后再动。

## 让 A 配合你的方式

- 需要新接口 / 新字段：直接说「哪个页面、要什么字段、怎么筛、怎么分页」，A 加进契约
- 契约不清楚：以 `http://127.0.0.1:8000/docs` 的实时文档为准
- 想先做页面不等后端：用 mock（S1-12），对着契约造数据
