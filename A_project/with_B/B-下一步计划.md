## 二、下一步计划（按性价比排序）

### P0 — 快速见效（约 0.7 人天）

#### 1. PDA 首页导航（0.3 天）

**为什么先做**：现在 PDA 有 4 个页面（扫码/库存速查/入库/出库），但**彼此之间没有任何入口**，
用户只能在浏览器输 URL —— 这是当前最明显的可用性缺口，也比任何新功能都便宜。

**做法**：
- 新建 `web/src/views/pda/home.vue`，`/pda` 路由指向它（现 redirect 到 `/pda/scan` 改掉）
- 4 张功能卡：库存速查 / 入库作业（收货·上架）/ 出库作业（拣货·发运）/ 扫码
- 按角色过滤（OPERATOR 以上可见作业卡，VIEWER 只看到速查）
- 顶部显示当前登录人 + 角色

**验收**：手机尺寸下 4 张卡可点，点击跳到对应页面，能返回首页。

---

#### 2. 库位管理（0.4 天）

**为什么第二**：最简单（1 个接口、13 条数据、无分页），能快速把「系统管理」这个空模块填上第一页。

**做法**：
- `system/locations`：列表 + 筛选（库区 `zone_code` / 类型 `location_type` / 状态 `status`）
- 列：库位编码、库区、货架、层、位、类型、拣货顺序、状态
- **不做**增删改（契约没有 `POST/PUT/DELETE /locations`）
- QUARANTINE 2 个位当前 0 库存，**不是 bug**，正常显示

**验收**：13 条全显示；按 `location_type=STORAGE` 筛出 7 条；编码是 `A0101` 格式。

---

### P1 — 核心价值（约 1.3 人天）

#### 3. 对账页（0.5 天）★ 推荐优先

**为什么**：它是「账实一致」的唯一可视化入口，验收时最有说服力，也能顺手验证后端账务是否真的对。

**做法**：
- 新建 `views/inventory/recon/index.vue` + 路由 `/inventory/recon`
- 顶部 4 个状态 tab：全部 / OK / MISMATCH / ONLY_INVENTORY / ONLY_TXN
- 列：SKU 编码、名称、库位、批次、效期、库存现存量、流水累计、差异、状态
- 配色：OK 绿、其余红；`diff_on_hand` 非 0 时标红加粗
- 权限：MANAGER/ADMIN（op01 会 403，正好验证错误码分流）

**验收**：14 条全 OK 一片绿；切 tab 数量正确；用 op01 登录看到 403 提示。

---

#### 4. SKU 管理（0.8 天）

**为什么**：商品主数据是入库/出库/库存的前提，虽然接口早就有了，但页面一直空着。

**做法**：
- 列表：`GET /skus?keyword=&category=&page=&page_size=`（**没有 status 筛选**）
- 详情：抽屉或独立页（`GET /skus/{id}`）
- 编辑：`PUT /skus/{id}`（字段全可选）
- 新建：`POST /skus`（必填 `sku_code` + `name`）
- **两条硬约束**：
  1. **编辑表单里 `sku_code` / `barcode` 必须设为只读**（契约没开放修改，传了也忽略，给可编辑是假象）
  2. `base_uom` 是中文（`箱/提/袋`），早期 3 个样例是 `BOX`——**不做单位枚举校验**

**验收**：13 条列表；搜索「矿泉水」命中；编辑改 `safety_stock` 成功；`sku_code` 输入框是禁用态。
